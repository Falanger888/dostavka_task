# Alliance Moving & Storage — Landing Page

Адаптивный одностраничный сайт (лендинг) для компании по грузоперевозкам. 
Проект выполнен в рамках тестового задания. Главная задача — точная Pixel Perfect верстка по макету из Figma, адаптация под мобильные устройства и написание интерактивных элементов на чистом JavaScript.

## ✨ Реализованный функционал

- **Адаптивная верстка**: сайт корректно отображается на десктопах (1920px+), планшетах и смартфонах (от 320px).
- **Мобильное меню (Бургер)**: кастомное открытие/закрытие меню, закрытие при клике вне его области. 
- **Форма обратной связи**: инпуты с валидацией (HTML5), правильными атрибутами `label` и `for` для доступности (Accessibility).
- **Сетка карточек**: использован CSS Grid для идеального выравнивания блоков услуг.
- **Интерактивность**: плавные hover-эффекты для карточек, кнопок и ссылок (включая кастомный курсор).
- **Интеграция карт**: встроенный iframe с Google Maps.
- **Блог и футер**: аккуратная структура контента и подвала.

## 🛠 Стек технологий

- **HTML5** (семантическая верстка)
- **CSS3** (Flexbox, CSS Grid, Media Queries, кастомные шрифты через `@font-face`)
- **Vanilla JavaScript** (работа с DOM, обработка событий клика)
- Без использования сторонних библиотек и фреймворков (jQuery, Bootstrap и т.д.)

## 🚀 Как запустить

Проект не требует сборки или установки зависимостей. 
1. Скачайте репозиторий или склонируйте его.
2. Откройте файл `index.html` в любом современном браузере.

## 📱 Брейкпоинты

- Десктоп: `> 992px`
- Планшеты: `768px - 992px`
- Мобильные устройства: `< 768px`
